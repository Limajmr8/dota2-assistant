# Instagram Reels Viral + Conversion Deployment (NPSC)

Use this as the operating playbook for Instagram growth and sales conversion.

## 1) Strategy Objective
- Get discoverable attention from NPSC aspirants using Reels.
- Convert attention to DM leads with keyword CTAs.
- Convert DM leads to buyers using the existing D0/D1/D3/D5 follow-up system.

## 2) Core Policies (Inspired by Top Growth/Sales Operators)
- **Offer-first policy (Hormozi style):** Lead with clear outcome and value stack, not vague motivation.
- **Proof-first policy (Ogilvy direct response):** Show sample pages, score improvements, user feedback.
- **Clarity policy (Jobs-style simplicity):** One Reel = one problem + one promise + one CTA.
- **Trust policy (Bezos-style customer obsession):** Use ethical claims only, no fake urgency/testimonials.
- **Consistency policy (Cialdini commitment principle):** Daily posting + predictable CTA keywords.

## 3) Reels Content Pillars (70/20/10)
- **70% Educational utility**
  - 1-minute concept explainers (Polity, NE GK, Article 371(A) traps)
  - Fast memory tricks (district-tribe, schemes, factual confusion pairs)
- **20% Proof and outcomes**
  - Before/after prep routine screenshots
  - Student wins, revision checklists, mock accuracy improvements
- **10% Offer promotion**
  - Bundle breakdown (260 Q bank + roadmap + prompts)
  - Intro/standard pricing reminders with ethical policy language

## 4) Viral Reel Structure (15–35 sec)
1. **Hook (0–2 sec):** call out pain or desired result.
2. **Pattern break (2–5 sec):** surprising fact/common mistake.
3. **Value (5–22 sec):** teach one actionable insight.
4. **Proof (optional):** sample screenshot/result snippet.
5. **CTA (final 3 sec):** “DM SAMPLE / FAST / ROADMAP”.

## 5) Hook Bank (Use/Rotate)
- “Most NPSC aspirants lose marks on this one Nagaland polity trap.”
- “If you have 30 days left, stop revising like this.”
- “This 2-step method fixes low mock accuracy fast.”
- “One Article 371(A) confusion can cost easy marks.”
- “Don’t buy more PDFs until you do this first.”
- “The highest ROI NPSC revision routine for working aspirants.”

## 6) Script Templates (Plug-and-Play)

### Template A — Pain to Solution
- Hook: “Still feeling random in NPSC prep?”
- Value: “Use this 20-minute loop: 10 MCQs + error log + 24h reattempt.”
- CTA: “DM ‘SAMPLE’ for a free mini pack.”

### Template B — Mistake Fix
- Hook: “You’re likely losing 5–10 marks from careless elimination.”
- Value: “Remove 2 impossible options first, then decide between 2.”
- CTA: “DM ‘FAST’ for the full revision system.”

### Template C — Offer Breakdown
- Hook: “What’s inside the NPSC Rank Accelerator?”
- Value: “260 questions + roadmap + active-recall prompts + revision cycles.”
- CTA: “DM ‘ROADMAP’ for details and current price.”

## 7) Caption + Hashtag Rules
- Caption structure:
  - Line 1: hook restatement
  - Line 2–3: value summary
  - Final line: single CTA keyword
- Keep hashtags focused and limited (5–12):
  - #NPSC #Nagaland #NPSCPreparation #NEIndia #CompetitiveExams
  - Add 2–4 contextual tags per topic (polity/economy/current affairs).

## 8) Posting Cadence (30 Days)
- **Daily:** 1 Reel minimum.
- **3 days/week:** 2 Reels/day (A/B hook testing).
- **Stories daily:** poll/question sticker + CTA to DM keyword.
- **Weekly Live (1x):** 20-minute doubt-clearing + offer CTA.

## 9) DM Funnel Integration
- Reel CTA keywords:
  - SAMPLE (free mini sample)
  - FAST (speed/revision angle)
  - ROADMAP (offer details)
- After DM trigger:
  - D0: sample + fit question + link
  - D1: reminder with one proof asset
  - D3: objection handling + testimonial
  - D5: final follow-up + current pricing status

## 10) KPI Dashboard for Reels
- Top-of-funnel:
  - Views, average watch time, 3-second hold rate, shares, saves
- Mid-funnel:
  - Profile visits, follows, DM keyword starts
- Bottom-funnel:
  - Conversations started, sales count, revenue per Reel

## 11) Scale/Cut Rules
- If 3-second hold rate is low for 3 days:
  - Change first 2-second hook format immediately.
- If watch time is good but DMs are low:
  - Improve CTA clarity and place CTA in spoken + on-screen + caption.
- If DMs are high but sales are low:
  - Tighten offer explanation and risk-reversal script.
- Scale the top 20% Reel topics that produce sales-qualified DMs.

## 12) 30-Day Deployment Sprint

### Week 1 — Setup + Baseline
- Publish 7 Reels with different hook angles.
- Track baseline metrics and best CTA keyword.

### Week 2 — A/B Hook Testing
- Test 3 primary hooks: Confidence, Speed, Cost.
- Keep same topic with different hook intros to isolate winner.

### Week 3 — Proof + Conversion Push
- Increase proof content (sample pages/testimonials/results).
- Run strong offer explainer Reels every 2nd day.

### Week 4 — Optimization + Systemization
- Remove low-performing formats.
- Double down on top-converting hook + topic + CTA combo.
- Document final repeatable Reel formats.

## 13) Compliance + Ethics
- Do not claim guaranteed rank/results.
- Do not use fake scarcity or fabricated testimonials.
- Keep messaging respectful, factual, and exam-supportive.
