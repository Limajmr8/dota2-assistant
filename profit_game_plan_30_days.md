# 30-Day Profit Execution Game Plan

Focus stream: NPSC one-time sales

## Core Rule
Every day must include:
1. Lead generation (30–50 new relevant prospects)
2. Follow-up block (Day 0 / Day 1 / Day 3 / Day 5)
3. End-of-day metrics update in NPSC tracker
4. One funnel improvement decision for next day

## Week 1 (Setup + First Sales)
- Finalize the offer stack as one result-focused bundle
- Publish lead magnet (10 questions + 2-day plan)
- Finalize DM scripts + Gumroad listing + onboarding copy
- KPI focus:
  - First 5 buyers
  - First 2 proof testimonials/screenshots

## Week 2 (Distribution Scale)
- Scale posting volume across Facebook + Telegram + WhatsApp communities
- Test 3 hooks:
  - Confidence angle
  - Speed/revision angle
  - Cost-vs-coaching angle
- KPI focus:
  - 30–50 leads/day average
  - Reach 20 cumulative buyers (price switch trigger)

## Week 3 (Conversion Optimization)
- Switch price to ₹499 after buyer #20
- Add ethical urgency (intro window closed / proof milestone reached)
- Launch upsell:
  - Interview Rapid Revision Add-on
  - Last 7 Days Crash Revision Plan
- KPI focus:
  - Maintain healthy conversion at ₹499
  - Increase revenue per buyer using upsell

## Week 4 (Retention + Repeatability)
- Push proof-heavy creatives (testimonials/results/sample screenshots)
- Retarget warm leads who did not buy in Weeks 1–3
- Document the repeatable daily sales workflow
- KPI focus:
  - Predictable weekly sales baseline
  - 30-day revenue and conversion targets hit

## Daily Non-Negotiables
- [ ] Reach out to 30–50 qualified prospects
- [ ] Run follow-ups by cadence (D0, D1, D3, D5)
- [ ] Share one proof asset (sample/testimonial/result)
- [ ] Log all numbers in tracker
- [ ] Decide one improvement for next day
